Architectural 3D and Interactive Visualization

A collection of university exercises exploring architectural modelling, material design, camera animation, and browser-based interactive 3D visualization.

The project was created with Blender and Verge3D and consists of four exercises covering different stages of a 3D visualization workflow.

Project Overview
01 — Architectural Modelling

A simplified classical building modelled from scratch in Blender.

The exercise included:

Creating the main building volume and pitched roof
Using Boolean modifiers to construct façade openings
Modelling roof beams and joists
Creating columns from a 2D profile with the Spin tool
Using Array modifiers for repeated architectural elements
Modelling windows, frames, façade details, and a panelled door

The Blender source file is included because the model was created independently by the author.

02 — Materials and Shading

Material development and UV mapping for a medieval market scene.

The work included:

UV mapping terrain, wooden structures, sacks, signs, and ceramic objects
Adjusting texture scale, orientation, and density
Creating procedural surface details with Noise Texture and Bump nodes
Developing materials for flour, wood, fabric, ceramics, and food objects
Adjusting roughness and reflectivity using Principled BSDF


03 — Camera Animation

Camera animations designed for a medieval market environment.

The exercise explored:

A courtyard overview shot
A gradual zoom towards a market stall
A human-eye-level walkthrough
Camera framing, movement speed, pauses, and local-axis transformations
Keyframe animation and spatial storytelling

The exported animation is included as a demonstration of the completed work.

04 — Verge3D Interaction

A browser-based interactive 3D experience developed with Verge3D.

The interaction design included:

Exporting a Blender scene as glTF
Adding clickable annotations to objects
Creating interaction logic with Verge3D Puzzles
Switching between orbit and first-person camera modes
Controlling camera position and focus during mode changes

Screenshots and recordings document the interaction without distributing the original course assets.
